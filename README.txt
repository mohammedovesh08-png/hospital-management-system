MEDICARE HOSPITAL MANAGEMENT SYSTEM
====================================

Technology:
- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

How to run:
1. Extract the ZIP.
2. Open login.html in a browser.
3. Demo username: admin
4. Demo password: admin123

Modules:
- Login
- Dashboard
- Patient Registration and Search
- Doctor Management and Search
- Appointment Booking and Search
- Billing
- Responsive layout

IMPORTANT:
This is a frontend/demo final-year project. Data is stored in browser LocalStorage.
For a real hospital system, add a secure backend, database, authentication,
authorization, encryption, audit logs and proper privacy/security controls.
